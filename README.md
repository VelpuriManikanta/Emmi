# EMMI Benchmark Monitoring Dashboard

**European Money Markets Institute (EMMI)**  
Mar 2023 – Jun 2024

## Project Overview

A secure data processing and API integration platform for benchmark monitoring and reporting in financial markets. Built with Django REST Framework backend and React frontend for real-time data retrieval, validation, and reporting.

## Key Features

- Real-time benchmark data monitoring and visualization
- Automated data processing and validation workflows
- Centralized reporting dashboards
- Secure API integration for financial data exchange
- SIT/UAT testing for application reliability and data accuracy

## Tech Stack

| Layer | Technologies |
|-------|-------------|
| Backend | Python, Django, Django REST Framework |
| Frontend | HTML, CSS, JavaScript, React |
| Database | PostgreSQL, SQL |
| Testing | SIT/UAT with QA and business teams |
